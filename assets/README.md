# Photo and icon placeholders

The site ships with labeled stand-in images so the layout is finished before the real photos exist. Replace each file **in place** and keep the same filename. You will not need to edit `index.html` if you do that.

Shoot or export RGB images. JPEG or PNG both work if you keep the filename below (a JPEG saved with a `.png` extension will not). If you would rather use `.jpg`, change the `src` in `index.html` to match.

| File | Where it shows | Replace with | Suggested size |
| --- | --- | --- | --- |
| `placeholder-hero-live-looping.png` | Hero, large photo | Neil live-looping: guitar, beatboxing, and vocals, with the Boss RC-505mkII in frame | 1600 × 1067 (3:2), landscape |
| `placeholder-sprinter-van.png` | Hero, second photo | The converted Sprinter van — exterior, or the inside set up as the mobile studio | 1600 × 1067 (3:2), landscape |
| `placeholder-sprinter-sessions.png` | Sprinter Sessions | A still from Sprinter Sessions, filmed in the van | 1400 × 933 (3:2), landscape |
| `placeholder-flow-arts.png` | Flow arts (secondary) | Neil with poi or other flow props. This section is supporting, not the headline | 1200 × 900 (4:3) |
| `placeholder-og-image.png` | Social share image (`og:image`, Twitter/Facebook/iMessage). Not shown on the page itself | A strong photo of Neil performing. This is the picture people see when the link is shared | **1200 × 630** exactly |
| `favicon.svg` | Browser tab icon | A real logo or mark, if you have one. The “N” monogram is a placeholder | Square SVG |
| `favicon-32.png` | Browser tab fallback | Same mark, rasterized | 32 × 32 |
| `apple-touch-icon.png` | Home-screen icon on phones | Same mark, rasterized | 180 × 180 |

Until these are swapped, every image on the page says **PHOTO NEEDED** or **PLACEHOLDER** on purpose.

The type files in `fonts/` are the real site fonts (Fraunces and Outfit, SIL Open Font License). They are not placeholders.
